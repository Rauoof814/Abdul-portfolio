# Abdul Rahmani Premium Portfolio

A luxury, animated, multi-page portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, Lucide icons, and React Three Fiber.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Add a new project

Open `src/data/projects.ts` and add a new project object. The Projects page and homepage will update automatically.

## Customize contact info

Edit `src/data/profile.ts`.
